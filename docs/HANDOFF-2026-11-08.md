## How to run both versions side by side
- Launcher -> Play: each version runs as `SVR06_PAL.exe` / `SVR06_USA.exe`; launching one only closes the same region. Logs: Logs page has a tab per version (`analysis\run_err.txt` = PAL, `run_err_usa.txt`, `run_out_usa.txt`). Live consoles are per build dir (`<build>\analysis\live`): `cmd.txt` in, `out.txt` out.
- Console commands: `shot <name>`, `vramdump`, `ramdump`, `gifcap N` (-> `analysis\live\gifcap.bin`), `threads`, `frame`, `quit`, ... (SvrConsole.cpp).
- Analysis tools (tools/): giftl.py (upload/draw timeline), gifdraws.py (per-draw state; PACKED regs not decoded), gifimg.py `<gifcap> <dbp-hex> [out]` (IMAGE upload stats), gifxfer.py (TRXDIR summary), svrlive.py (console client).
- Remember: use `device_bash` for the user's files; Linux VM cannot run PowerShell/Windows tools; `timeout` on greps over PS2Recomp trees.
